# CWA-2026-002: Malicious balance operations

**Severity**

Critical (Likely + Catastrophic)[^1]

**Affected versions:**

- wasmd ≥ v0.61.0, ≤ v0.61.8 

**Patched versions:**

- wasmd v0.61.9

## Description of the bug

This bug may allow malicious balance operations.

To be affected, the chain need to be on wasmd `v0.61.x` and have `IBCv2` enabled.

## Patch

This patch is not consensus-breaking, prevents attacker from malicious balance operations.

## Applying the patch

Chains MUST upgrade **wasmd** to the patched version:
- `v0.61.9`

## Timeline

- 2026-03-18: Patch has been released.

[^1]: Following Amulet's [Severity Classification Framework ACMv1.2].
