# CWA-2026-003: Delayed block production

**Severity**

Medium (Possible + Moderate)[^1]

**Affected versions:**

- wasmd ≤ v0.61.9
- wasmd ≤ v0.60.8
- wasmd ≤ v0.54.7

**Patched versions:**

- wasmd v0.61.10
- wasmd v0.60.6
- wasmd v0.54.7

## Description of the bug

This bug can allow an attacker to cause significant delays in block production.

## Patch

This issue will be resolved in a consensus-breaking patch release in wasmd.
Chains are required to upgrade wasmd depending on the version they are currently running.
We strongly recommend all networks upgrade as soon as possible to ensure chain stability and security.

## Applying the patch

Chains MUST do a coordinated upgrade **wasmd** to one of the patched versions:
- `v0.61.10`
- `v0.60.6`
- `v0.54.7`

## Timeline

- 2026-04-01: Patch has been released.
