# CWA-2026-005: Large number of locals in Wasm functions may stall the chain

**Severity**

High (Possible + Considerable)[^1]

**Affected versions:**

Only supported versions listed:

- cosmwasm ≤ v2.2.8, v2.3.3, ≤ v3.0.7
- wasmvm ≤ v2.2.7, v2.3.3, ≤ v3.0.6
- wasmd ≤ v0.54.8, v0.60.7, ≤ v0.61.13, ≤ v0.70.2

**Patched versions:**

- cosmwasm v2.2.9, v2.3.4, v3.0.8
- wasmvm v2.2.8, v2.3.4, v3.0.7
- wasmd v0.54.9, v0.60.8, v0.61.14, v0.70.3

## Description of the bug

Permissionless CosmWasm chains can be stalled by storing and executing
malicious smart contracts having a large value of local variables defined
in one or more Wasm functions.

## Patch

This is **consensus braking** patch that provides limits on allowed amount
of locals in functions and charges additional gas for large number of locals
in a Wasm function.

## Applying the patch

Chains MUST upgrade to one of the patched versions:
- **wasmd** `v0.54.9` with **wasmvm** `v2.2.8` with cosmwasm-std `v2.2.9`
- **wasmd** `v0.60.8` with **wasmvm** `v2.3.4` with cosmwasm-std `v2.3.4`
- **wasmd** `v0.61.14` with **wasmvm** `v3.0.7` with cosmwasm-std `v3.0.8`
- **wasmd** `v0.70.3` with **wasmvm** `v3.0.7` with cosmwasm-std `v3.0.8`

Patched version must be applied to all validator nodes simultaneously,
because it MAY break the consensus if contracts deployed on chain contain
a large number of locals in compiled Wasm functions.

## Timeline

- 2026-05-28: Report sent by Cosmos Labs to Hadron Labs.
- 2026-06-24: Patch has been released.
