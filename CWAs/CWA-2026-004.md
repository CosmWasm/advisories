# CWA-2026-004: Chained overflows allow to bypass gas limits

**Severity**

Low (Unlikely + Moderate)[^1]

**Affected versions:**

Only supported versions listed:

- cosmwasm-vm ≤ v3.0.5
- cosmwasm-vm ≤ v2.3.2
- cosmwasm-vm ≤ v2.2.7

**Patched versions:**

- cosmwasm-vm v3.0.6
- cosmwasm-vm v2.3.3
- cosmwasm-vm v2.2.8

## Description of the bug

Three chained integer overflows in the CosmWasm VM gas accounting layer allow
a malicious or buggy chain backend to bypass gas limits entirely.

## Patch

This is non-consensus braking patch that fixes overflowing arithmetic operations.

## Applying the patch

Chains MUST upgrade to one of the patched versions:
- **wasmd** `v0.70.2` with **wasmvm** `v3.0.6` with cosmwasm-vm `v3.0.6`
- **wasmd** `v0.61.13` with **wasmvm** `v3.0.6` with cosmwasm-vm `v3.0.6`
- **wasmd** `v0.60.7` with **wasmvm** `v2.3.3` with cosmwasm-vm `v2.3.3`
- **wasmd** `v0.54.8` with **wasmvm** `v2.2.7` with cosmwasm-vm `v2.2.8`

## Timeline

- 2026-04-14: Report sent by Cosmos Labs to Hadron Labs.
- 2026-05-06: Patch has been released.
