# CWA-2026-001: Node memory saturation

**Severity**

Medium (Unlikely + Considerable)[^1]

**Affected versions:**

- wasmd v0.61.7
- wasmd v0.60.4
- wasmd v0.54.5
- wasmvm v3.0.2
- wasmvm v2.3.1
- wasmvm v2.2.5

**Patched versions:**

- wasmd v0.61.8
- wasmd v0.60.5
- wasmd v0.54.6
- wasmvm v3.0.3
- wasmvm v2.3.2
- wasmvm v2.2.6

## Description of the bug

This bug can cause memory saturation which can lead to crashes of the node process.

## Patch

This patch is not consensus-breaking, prevents node from memory saturation.

## Applying the patch

Chains have to bump these versions depending on which version they currently have:
- wasmd `v0.61.8` with wasmvm `v3.0.3`
- wasmd `v0.60.5` with wasmvm `v2.3.2`
- wasmd `v0.54.6` with wasmvm `v2.2.6`

## Timeline

- **2026-02-11**: Patch has been released.
